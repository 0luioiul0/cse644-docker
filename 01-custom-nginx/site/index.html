This page is served from a customized Nginx image.

The base image is nginx:1.27-alpine straight from Docker Hub. The Dockerfile in 01-custom-nginx/ deletes the stock welcome page, copies this hand-written site in its place, and drops in a small server block that adds an X-Served-By header and a /whoami endpoint. If you are reading this instead of the default Nginx landing page, the customization built and ran correctly.
