__BACKEND__

HAProxy listens on port 8082 of the host and forwards to the nginx_pool backend, which contains two Nginx containers (web1 and web2) on an internal Docker network. The Nginx containers publish no host ports at all, so from outside this machine the proxy is the only way in. Reload this page and the backend name above alternates, which is the round-robin balancer at work. 

curl -s  http://localhost:8082/whoami   # alternates web1 / web2
curl -sI http://localhost:8082/         # X-Proxied-By and X-Backend-Server headers
open     http://localhost:8404/         # HAProxy stats: both backends UP
