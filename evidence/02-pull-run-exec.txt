---------------------------------------------------------------
STEP: Open an interactive shell session inside the running container
---------------------------------------------------------------

A pseudo-terminal is allocated with script(1) so the transcript below is a
real interactive bash session: the prompt, the typed commands and their
output all come from inside the container.

$ docker exec -it -e TERM=dumb cse644-exec-demo bash --noediting
  (--noediting and TERM=dumb only keep the saved transcript free of terminal
   redraw escapes; 'docker exec -it cse644-exec-demo bash' behaves the same at a keyboard.)
